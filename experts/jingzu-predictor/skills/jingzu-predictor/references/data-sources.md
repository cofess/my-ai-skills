# titan007 数据链：契约与陷阱手册

> 全部为**实测踩过的坑**。抓数前先读，能省掉大量返工。
> 站点编码：**GBK / GB18030 为主，但不固定** —— 同一 URL 可能这次返回 GB18030、下次返回 UTF-8（见 T10）。
> ⇒ 抓原始 HTML 必须**先探 `Content-Type` / `<meta charset>` 再解码**；按固定编码硬解会让中文变乱码，**按场次过滤时静默返回空集**。
> WebFetch 返回的中文一般正常（它自带编码探测）。

## 1. 竞彩赛程页（竞彩官方 SP）

```
https://cp.titan007.com/buy/jingcai.aspx?typeID={101|102|103|104}&date=YYYY-MM-DD
```

**可回溯任意历史日**（实测回溯至 2026-08-26 正常，**无 30 天窗口限制**）；不传 `date` 返回当日。

> ⚠ 抓取**必须带 cache-buster**（`&_=<时间戳+随机数>`）+ `Cache-Control: no-cache` —— 否则 CDN 陈旧缓存会**静默返回错页**（年份/期号错、甚至 0 行）且不报错，见陷阱 **T12**。
> 对照：`trade.500.com/jczq/?playid=..&date=..` 仅保留约 **30 天**，更早日期一律 302 丢参 ⇒ 历史回补**已弃用**该源。

| typeID | 玩法 |
|---|---|
| 101 | **让球**胜平负（"参考奖金 主胜/平局/客胜"三列**挂在"让球"分组下**） |
| 102 | 比分（31 档） |
| 103 | 进球数（0–7+） |
| 104 | 半全场（9 组合） |

### 1.1 ★ 不让球 SPF 可得（2026-10-16 勘误，原「不发布」结论已证伪）

`typeID=101` 页面**每场含两组三列**：

| 单元格 | 含义 | 验证 |
|---|---|---|
| `cell_{mid}_1 / _2 / _3` | **让球胜平负 SP**（让胜/让平/让负） | 与 500 的 `spf` 逐值相同 |
| `cell_{mid}_52 / _53 / _54` | **不让球胜平负 SP**（主胜/平局/客胜） | 与 500 的 `nspf` 逐值相同 |

实例：周二003 布里兰-北京国安（让球 -1）：`cell_1/2/3` = 3.35/3.50/1.84 ≡ `spf`；`cell_52/53/54` = 1.74/3.92/3.35 ≡ `nspf`。

⇒ 本库 `nspf` **可直接取赛程页真实竞彩 SP**，「用即时平均欧指替代」**不再是必需的降级方案**（旧「titan007 不发布不让球 SPF」结论**已证伪**，见校正日志 **D17**）。

> ⚠ **深盘场（让球绝对值≥2）两源都不售不让球盘** —— `cell_52/53/54` 缺失，且原 500 源 **100% 同样缺失** ⇒ 属市场结构事实，**保留为空、不用欧指替代**（避免再次造成口径污染）。

### 1.2 赛程页行内数字串解码

每场行内的数字串形如：

```
平均欧指(初盘) | [变] 即时欧指 | 竞彩让球盘口 | 让球胜平负 SP
```

实例：`**-1** 4.30 3.92 1.56` = **让 1 球（主让）**，让胜 4.30 / 让平 3.92 / 让负 1.56。

- **让球数为负 = 主让**（`-1` 主让一球）；客让为正（`+1`）。
- 初盘与即时欧指之间可能夹「变」标记，**不要把它当数字**。
- **两组三列**：`cell_{mid}_1/2/3` = 让球胜平负 SP、`cell_{mid}_52/53/54` = **不让球胜平负 SP**（见 §1.1）—— 两组在 HTML 中相邻，解析时勿串组。

### 1.3 比分 31 档「默认隐藏、但服务端已渲染」—— 可直接解析（★ 2026-10-16 重大勘误）

赛程页比分（typeID=102）**每场 31 档全部由服务端渲染进 HTML**，只是包在 `<tr>` 里、以 `style="display:none"` 隐藏。
所谓「展开▼」只切一个 CSS 属性，**不触发 AJAX、不触发重渲染**：

```html
<td id="sp_5555002" class="closeMore" onclick="setBetMatch(this,'tr_5555002');">展开▼</td>
<tr id="tr_5555002" style="display:none;">   <!-- 31 档比分 SP 全在这里 -->
```

展开态是 `display: ;`、收起态是 `display:none`，**两态数据一字不差**。
⇒ **无需模拟点击、无需找接口，直接解析原始 HTML 即可拿到全部场次的 31 档比分 SP**
（实测当日 58 场全部带隐藏明细，逐 idx 与官方档位表核验零处不符）。

> ⚠ **旧结论「除个别展开场次外比分 SP 不可得」已证伪**，见校正日志 **D13**。
> 用 WebFetch 提取会丢失 HTML/JS（见 T2）⇒ 必须用 HTTP 客户端抓**原始页面**再解析。

### 1.4 比分 SP 变化页不可用（保留，但已非必需）

```
https://cp.titan007.com/sp/zuqiu/{编号}_{type}.html
```
该页数字**无缝拼接**（小数位粘连，如 `9.5102`），无法可靠切分回 31 个比分选项。
⇒ **仍弃用该路径，拒绝猜测性切分**；但自 §1.3 勘误后**已无此需求** —— 比分 SP 直接从赛程页原始 HTML 解析。

## 2. 亚指页

```
https://vip.titan007.com/AsianOdds_n.aspx?id={赛事ID}
```

- 内容 = **顶部各公司汇总表**（初盘盘口 + 上盘水位 + 下盘水位；即时盘口 + 水位） + **完整变化历史**（数据量极大）。
- 若需初盘／盘中／尾盘三时点：从变化史取「最早一条 / 中间一条 / 最新一条」。
- **页面极大（15–20KB+）** ⇒ 必须用限行提取提示词（见 §6）；但**限行对这类页只是软约束、且不可靠**（见 T9）。

## 3. 大小球页

```
https://vip.titan007.com/OverDown_n.aspx?id={赛事ID}&l=0
```

- 内容 = 当前盘口 + 大球水位 + 小球水位 + 变化历史。
- **升盘 / 降盘次数是强信号**（例：升盘 14 次 = 全轮最强信号；降盘 5 次 + 低水 8 次 → 小球）。
- 同样必须限行提取；同样受 **T9** 制约 —— 失败率高，**优先逐场定向提问、失败即止**。

## 4. 数据分析页（**最高效聚合源，优先抓**）

```
https://zq.titan007.com/analysis/{赛事ID}cn.htm
```

一次即可拿到：

- 两队**积分排名**
- 两队**近期战绩**（比分 + 盘路赢输 + 大小球 + 单双）
- **历史交锋**（H2H）
- **相同盘路统计**
- 得失球分布
- **赛前简报（含伤停情报）**
- 阵容评分

⇒ 与其他页冲突时，**先把这一页抓全**，再用其他页补充盘口细节。

## 5. 情报页（付费墙）

```
https://users.titan007.com/member/qingbao.aspx
```

返回「本场已更新 N 条情报，解锁或订阅后可立即查看」⇒ **标记数据缺失**，
用分析页「赛前简报」中的伤停信息兜底。**不得编造情报**。

## 6. WebFetch 提取提示词模板（限行是硬要求）

**亚指页**

```
这是亚指页面。只输出：1) 当前盘口+上盘水位+下盘水位；2) 最近 5 次变化（时间+盘口+水位）；
3) 历史中最早一次开盘记录（时间+盘口+水位）。不超过 12 行。
```

**大小球页**

```
这是大小球页面。只输出：1) 当前盘口+大球水位+小球水位；2) 最近 3–5 次变化；
3) 页面顶部汇总表各公司的初盘/即时盘口与水位（只列主流公司）。不超过 20 行。
```

**分析页**

```
这是足球数据分析页面。只输出：1) 两队积分排名；2) 两队近期战绩各 5–8 场（比分+盘路+大小）；
3) 历史交锋近 5 场；4) 相同盘路统计；5) 赛前简报/伤停情报；6) 阵容评分。不超过 40 行。
```

**赛程页（单玩法）**

```
只提取【不让球胜平负】列表中编号 001 到 011 的每一场：编号、主队VS客队、主胜SP、平局SP、客胜SP。
每场一行，共 11 行。不要输出其他内容。
```

> 不加行数限制时，亚指/大小球页会返回数百行（含 300+ 家公司历史），直接撑爆上下文。
> ⚠ **「不超过 N 行」只是软约束**：实测 11 场亚指页仅 2 场被正确压到 ≤8 行，其余 9 场
> 仍返回 300+ 行全量变化史（**单次即撑爆上下文**）⇒ 见 **T9**，**不要批量并发抓这类页**。

## 7. 陷阱清单

| # | 陷阱 | 处置 |
|---|---|---|
| T1 | 亚指/大小球原始 HTML 极大 | 提取提示词**必须限行** |
| T2 | WebFetch 把 ASPX 表格**压平成拼接数字串** | 比分表不可解析 → 拒用 |
| T3 | 比分 SP 变化页小数位粘连（`9.5102`） | 无法切分 → 弃用该路径 |
| T4 | 情报页付费墙 | 标缺失 + 分析页兜底 |
| T5 | 赛程页**只有初盘 + 即时**两值时点 | 「盘中」缺失 → 以即时值近似并披露 |
| T6 | 抓取时点 ≠ 赛前最终尾盘 | 「尾盘」应标注为「抓取时点最新值」，并注明距开赛时长 |
| T7 | 让球数符号 | **负 = 主让**，正 = 客让，0 = 平手 |
| T8 | 期号前缀决定环境 | 竞彩期号前缀（周X）是**开奖日**；凌晨开球场次属前一天期号 ⇒ 判「工作日/周末」**以期号前缀为准**，不以开球时刻为准 |
| T9 | **亚指/大小球页的「限行提示词」不可靠** | 实测 11 场亚指页仅 2 场被正确限行，9 场返回 300+ 行全量史（单次撑爆上下文）⇒ **逐场抓、失败即止**；改用「只问当前盘口 / 最早一条 / 最近 3 次变化」的定向提问，**勿批量并发** |
| T10 | **同一 URL 编码漂移**（GB18030 ↔ UTF-8） | 首抓 GB18030、复核抓 UTF-8；按固定编码解码 → 中文乱码 → **按场次过滤时静默返回空集**（不报错）⇒ 抓取前先探 `Content-Type`/`meta charset` |
| T11 | **隐藏明细每请求重渲染** | 比分等隐藏明细随每次请求重渲染：实测数分钟内 004 有 7 档变化（全在长尾档）⇒ 引用**必须带采集时点**，不同时点数据不得混用 |
| T12 | **CDN 陈旧缓存（静默返回错页）** | 不带唯一查询参数时，`...&date=2026-09-26` 曾返回**错误的期号+年份**（页头 `2020年09月25日 星期五`/12 行）或直接 **0 行**。加 cache-buster（`&_=<时间戳+随机>`）+ `no-cache` 后稳定返回正确页（`2026年09月26日 星期六`/24 行）⇒ **抓该站必须带 cache-buster**，否则静默拿旧页且不报错（与 T10 同属「静默错误」家族） |

## 8. 默认不可得（勿伪造）

| 维度 | 状态 | 替代 |
|---|---|---|
| 竞彩不让球 SPF | ✅ **可得**（`cell_52/53/54`，2026-10-16 勘误 **D17**）｜深盘场（让球绝对值≥2）两源均不售 | 直接取赛程页 SP；深盘场**保留为空、勿用欧指替代** |
| 完整比分 SP | ✅ **可得**（31 档服务端已渲染，见 §1.3；2026-10-16 勘误 D13） | 直接解析赛程页**原始 HTML**（31 档/场），勿经 WebFetch |
| 初盘→盘中→尾盘漂移 | ⚠ 仅初盘/即时两点 | 亚指/大小球变化史可部分重建 |
| 成交量 / 热度 / 资金流 | ❌ 无公开接口 | 无 |
| 付费情报（伤停细节） | ❌ 付费墙 | 分析页「赛前简报」 |
| 单场欧指多公司初/即对比 | ⚠ `op1.titan007.com/oddslist/{id}.htm` 含 300+ 公司 | 限行提取，只取主流公司 |
