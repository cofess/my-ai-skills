# 分环境方法集（工作日 / 周末，零重叠）

> 本文件是 skill 的核心结论层。**两套方法集在 6/6 玩法档位上零重叠** —— 不存在任何一条跨环境共用的规则。
> **数值口径（2026-10-16 起）**：基于 titan007 单源**全量重建**数据集（四玩法覆盖 100% / 不让球 90%）。旧 500 源（覆盖仅 50%/70%）的数值已废止，修订过程见 `calibration-log.md` 第九轮。

## 0. 样本与口径

| 环境 | 数据文件 | n | 区间 | 构造 |
|---|---|---|---|---|
| 工作日 | `master300_odds.json` | 300 | 2026-08-29 ~ 2026-10-13 | 排除周六/周日 |
| 周末 | `master200_wk_odds.json` | 200 | 2026-09-12 ~ 2026-10-12 | 仅周六/周日 |

- **输入仅用赛前可得信息**：让球盘口 + 终盘赔率（`nspf / spf / jqs / bqc / bf`）。开奖 SP 只用于结算与校准，**不作预测输入**（无未来函数）。
- **终盘赔率 = 竞彩 SP**（titan007 赛程页；`nspf` 取 `cell_52/53/54`，见 `data-sources.md` §1.1）。深盘场（让球绝对值 ≥ 2）多数无不让球盘 ⇒ 相关门控排除，**不用欧指替代**。
- **时序留出**：按日期排序，前 60% 校准 / 后 40% 验证。所有「验证」列均为**留出期**表现。
- **结算口径**：多选打法 **注数 = 选数**（见铁律 3）。
- 复现：`sep_final.py`（见 `scripts/`）。

## 1. 环境事实（分环境建模的硬依据）

| 指标 | 工作日 300 | 周末 200 | 显著性 |
|---|---|---|---|
| 主胜率 | 50.7% | 46.0% | p=0.306 |
| **平局率** | **19.7%** | **28.0%** | **z=2.16, p=0.031 ★** |
| 客胜率 | 29.7% | 26.0% | — |
| 场均进球 | 3.04 | 2.99 | — |
| 大球(≥4) | 37.3% | 33.5% | p=0.381 |
| **让球盘结果 ≠ 不让球结果** | 50.7% | **56.5%** | → 周末让球不可测 |

**分水岭 = 平局率**：工作日平局少 → **盘口/让球方向法成立**；周末平局多 → 盘口法塌陷，必须换成**赔率条件筛选法**。

## 2. 工作日方法集（6 条）

### 2.1 胜平负 · 主推 —— 深盘跟盘

```python
fn = lambda r: (('3' if rqv(r) < 0 else '0') if abs(rqv(r)) >= 2 else None)   # None = 不出手
```

| 指标 | 值 |
|---|---|
| n / 命中 | **44 / 39 = 88.6%** |
| 留出验证 | 校准 86.7% → **验证 92.9%** |
| 显著性 | 88.6% vs 基准全主胜 50.7%，**z=4.73, p<0.0001 ★** |
| ROI | +5.00%（**可结算仅 14 注**，CI −11.3~+21.3，t=0.60） |

> ⚠ 深盘**只报方向命中率**：深盘场多数无不让球赔率（可结算仅 14/44）。错因分解：5 场未命中中 **平局 4 场（80%）**、方向押反 1 场 ⇒ **深盘必挂防冷平**。

## 3. 周末方法集（7 条）

### 3.1 胜平负 · 主推 —— A 级三条件

```python
fn = lambda r: ('3' if (fav(o5(r,'nspf'))=='3'
                        and .60 <= favp(o5(r,'nspf'))[1] < .70
                        and 1.30 <= (fnum(o5(r,'nspf').get('3')) or 0) < 1.60) else None)
```

> 条件 = 市场热门隐含概率 **p∈[0.60,0.70)** ∩ 最低赔率 **∈[1.30,1.60)** ∩ **主胜为热门**

| 指标 | 值 |
|---|---|
| n / 命中 | 20 / 15 = 75.0% |
| 留出验证 | 校准 55.6% → **验证 90.9%** |
| 显著性 | **z=2.47, p=0.0134 ★**（较旧小样本 z=3.20 走弱） |
| ROI | +3.35%（注 20，CI −23.5~+30.2，t=0.24，**CI 跨 0**） |

> **周末专用**：工作日同条件仅 74.1%（不显著）⇒ 从工作日档位移除（校正项 W10-a）。

|---|---|

## 7. ROI 诚实披露（本轮总结论）

- **达显著为负**（新样本）：工作日·让球胜平负 **−25.17%**(t=−2.13)、周末·进球数 Top3 **−13.42%**(t=−2.86)、工作日·大球 {4,5,6,7+} **−23.83%**(t=−3.24)、周末·大球 **−32.56%**(t=−4.00)。
- **正向且留出不崩**：周末·概率差≤15pp 押{主,平} **+16.93%**(t=2.19，验证 87.0%)；周末·进球数 60%+ 场次命中率最高，但 ROI 仍负。
- overround ≈ 1.13（抽水 ≈ 13%）是所有打法长期为负的结构性原因。
⇒ **本轮没有任何方法被证明为正期望。命中率 ≠ 盈利。**
