# 分环境方法集（工作日 / 周末，零重叠）

> 本文件是 skill 的核心结论层。**两套方法集在 6/6 玩法档位上零重叠** —— 不存在任何一条跨环境共用的规则。

## 0. 样本与口径

| 环境 | 数据文件 | n | 区间 | 构造 |
|---|---|---|---|---|
| 工作日 | `master300_odds.json` | 300 | 2026-08-29 ~ 2026-10-13 | 排除周六/周日（周一59/周二70/周三55/周四39/周五77） |
| 周末 | `master200_wk_odds.json` | 200 | 2026-09-12 ~ 2026-10-12 | 仅周六/周日（周六109/周日91） |

- **输入仅用赛前可得信息**：让球盘口 + 终盘赔率（`nspf / spf / jqs / bqc / bf`）。开奖 SP 只用于结算与校准，**不作预测输入**（无未来函数）。
- **时序留出**：按日期排序，前 60% 校准 / 后 40% 验证。所有「验证」列均为**留出期**表现。
- **结算口径**：赔率 = 500 终盘；多选打法 **注数 = 选数**（见铁律 3）。
- 复现：`sep_final.py`（见 `scripts/`）。

## 1. 环境事实（分环境建模的硬依据）

| 指标 | 工作日 300 | 周末 200 | 显著性 |
|---|---|---|---|
| 主胜率 | 50.7% | 46.0% | p=0.306 |
| **平局率** | **19.7%** | **28.0%** | **z=2.16, p=0.031 ★** |
| 客胜率 | 29.7% | 26.0% | — |
| 场均进球 | 3.04 | 2.99 | — |
| 大球(≥4) | 37.3% | 33.5% | p=0.381 |
| **让球盘结果 ≠ 不让球结果** | 50.7% | **56.5%** | → 周末让球不可测 |
| 进球数 Top3 命中 | 58.2% | **66.4%** | → 周末值域更集中 |
| 盘口倾斜法 | 62.7% | 56.5% | p=0.168 |

**分水岭 = 平局率**：工作日平局少 → **盘口/让球方向法成立**；周末平局多 → 盘口法塌陷，必须换成**赔率条件筛选法**。

## 2. 工作日方法集（6 条）

### 2.1 胜平负 · 主推 —— 深盘跟盘

```python
fn = lambda r: (('3' if rqv(r) < 0 else '0') if abs(rqv(r)) >= 2 else None)   # None = 不出手
```

| 指标 | 值 |
|---|---|
| n / 命中 | **44 / 39 = 88.6%** |
| 留出验证 | 校准 86.7% → **验证 92.9%** |

## 3. 周末方法集（7 条）

### 3.1 胜平负 · 主推 —— A 级三条件

```python
fn = lambda r: ('3' if (fav(o5(r,'nspf'))=='3'
                        and .60 <= favp(o5(r,'nspf'))[1] < .70
                        and 1.30 <= (fnum(o5(r,'nspf').get('3')) or 0) < 1.60) else None)
```

> 条件 = 市场热门隐含概率 **p∈[0.60,0.70)** ∩ 最低赔率 **∈[1.30,1.60)** ∩ **主胜为热门**

| 指标 | 值 |
|---|---|
| n / 命中 | 16 / 14 = 87.5% |
| 留出验证 | 校准 80.0% → **验证 90.9%** |
| 显著性 | **z=3.20, p=0.0014 ★** |
| ROI | **+20.81%**（注 16，CI −2.4~+44.0，t=1.76，**CI 跨 0**） |

> **周末专用**：工作日同条件仅 74.1%（z=1.45, p=0.1472 不显著）⇒ 从工作日档位移除（校正项 W10-a）。

### 3.4 让球胜平负 —— 【回避】

## 7. ROI 诚实披露（本轮总结论）

- **绝大多数可结算打法 95%CI 跨 0**；达显著的 **2 项全为负**：
  - 周末·半全场 Top3 且 p≥60%：**−20.85%**（CI −40.5~−1.2，t=−2.08）
  - 周末·进球数 Top3：**−10.62%**（CI −21.2~−0.1，t=−1.97）
- overround ≈ 1.13（抽水 ≈ 13%）是所有打法长期为负的结构性原因。
⇒ **本轮没有任何方法被证明为正期望。命中率 ≠ 盈利。**

> 口径注记（D12）：本文件 ROI 均为**应用 D9 别名表后**的数值（`7+`→`7`、`胜其他`→`胜其它`），
