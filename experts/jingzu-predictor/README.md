# 竞足双轨预测大师（jingzu-predictor）

竞彩足球「分环境双轨」预测与回测专家 —— **工作日与周末各用一套互不相同、经留出验证的固化方法集**。基于公开赔率与赛果做**统计分析与回测**，输出可复验的胜平负、比分、进球数与半全场预测，并持续校正方法。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **分环境判定与路由**：按竞彩期号（周一~周五 / 周六周日）判定环境，套用对应方法集，两套规则**零重叠、绝不混用**。
- **titan007 数据链采集**：竞彩赛程页五玩法 SP（含不让球胜平负）、亚指、大小球、数据分析页（含伤停简报），内置数字串解码契约与陷阱清单。
- **四玩法预测**：胜平负 / 比分（31 档）/ 进球数（0–7+）/ 半全场（9 组合），输出隐含概率、概率差、Top3 与置信度分级。
- **双环境回测与校正**：工作日 300 场 + 周末 200 场，输出命中率、留出验证、错因分解、ROI 与 95%CI。
- **四专项规则库**：爆冷预警、平局识别与下注、高赔比分识别、大球识别、半全场反转识别。
- **规则真源共用**：`scripts/env_rules.py` 为唯一规则源，回测与当日预测 `import` 同一份代码，杜绝「回测一套、预测另一套」。

## 核心结论摘要

**6/6 档位规则零重叠**（两环境不含任何同一条规则）：

| 档位 | 工作日（n=300） | 周末（n=200） |
|---|---|---|
| 胜平负·主推 | 深盘跟盘 \|让球\|≥2 → **88.6%**（验证 92.9%） | A 级三条件 → **75.0%**（验证 90.9%） |
| 胜平负·可结算 | 主胜热门 p≥60% → 77.6% | 市场热门 p≥70% → 83.3% |
| 让球胜平负 | 让球热门 p≥60% → 54.3%（n=35，负期望） | **【回避】** |
| 比分 | Top3 ∩ 概率差<20pp → 33.0% | Top3 ∩ 仅客让 → 33.8% |
| 进球数 | 固定 1–3 球 ∩ 仅主让 → 57.7% | 隐含 Top3 全样本 → **64.5%** |
| 半全场 | Top3 ∩ 仅深盘 → **90.0%**（n=40） | Top3 ∩ 热门 p≥60% → 78.9% |

**分水岭**：平局率 工作日 19.7% vs 周末 **28.0%**（z=2.16, p=0.031 ★）；
最典型跨环境反例 —— 平赔≤3.4 押平局：工作日 ROI **−22.41%** vs 周末 **+36.27%**（符号相反）。

## 内置四条重点规则

| 规则 | 定义 | 已标定事实 |
|---|---|---|
| 深盘低爆冷 | \|让球\|≥2 | 爆冷 1/14（工作日）、1/6（周末），远低于基准；未命中**以平局为主** |
| 高赔比分不可识别 | 比分 SP ≥ 15 | 20 次评估最大提升仅 **1.18x**；基准率本身 31–38% |
| 大球负期望 | 总进球 ≥ 4 | {4,5,6,7+} 工作日 **−23.83%** / 周末 **−32.56%** |
| 半全场反转 | 胜平/负平/胜负/负胜 | 工作日 16.1%（基准 11.5%）；周末 **验证崩至 11.8%（已证伪）** |

## 使用示例

- 分析今天的竞彩赛程，按工作日/周末方法集给出胜平负、比分、进球数、半全场预测。
- 回测 300 场工作日与 200 场周末赛事，收敛出两套互不相同、经留出验证的最优方法。
- 用球探网初盘与尾盘赔率分析这场深盘比赛，并评估爆冷与平局风险。
