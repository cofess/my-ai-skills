# 足彩预测大师（football-lottery-analyst）

> 目标不是「给一个结果」，而是：**分析 → 预测 → 比对赛果 → 校正方法 → 找到准确率最高且经得起 ROI 检验的预测方法**。
> 领域定位：基于公开数据（赔率 + 开奖结果）的**统计分析与历史回测**，属信息分析用途，**不构成投注建议**。

## 何时使用

- 用户要求分析某日竞彩/足彩赛程，要胜平负 / 比分 / 进球数 / 半全场预测。
- 用户要求「回测 N 场」并按赛果比对命中率、做校正闭环。
- 用户提到：爆冷、高赔比分、大球、半全场反转、盘口倾斜法、深盘跟盘、隐含概率。
- 用户给出 500.com / 澳客的竞彩链接，或贴出赔率页面文本要求解读。

## 四条铁律（先读，违反即作废）

1. **不编造数据**。链接不可访问、字段缺失时，必须显式标注「不可得」并给出替代源建议，**绝不用记忆或推测填补赔率、赛果、伤停**。
2. **命中率 ≠ 盈利**。竞彩终盘 overround 实测 **1.129（抽水 ≈ 12.9%）**，本库所有打法的 ROI 长期为负。任何"方法更好"的结论必须先过 **ROI 门槛**（`roi_stats` 给出 ROI / t / 95%CI），**CI 跨 0 即等于零**，不得当正期望宣传。
3. **分环境建模**。**周末 ≠ 工作日**：平局率 28.0% vs 19.7%（z=2.17, p=0.030 显著）、进球数隐含 Top2 50.3% vs 38.2%（显著）。**禁止把两个环境的方法战绩混用**；产出时必须声明样本是「工作日 / 周末 / 合并」。
4. **诚实披露 scope**。每份产出末尾必须列明"本轮不可得"的维度（见下）与样本量不足的项，明确区分**已结论 vs 待扩样观察**。

## 数据源与降级协议

| 源 | 能给 | 已知边界 |
|---|---|---|
| `trade.500.com/jczq/`（playid 354/271/270/272） | 四玩法**完整终盘赔率**；历史日页还带已完赛比分 | **只回溯约 30 天**，更早日期返回 302 降级；**胜平负(不让球)页系统性缺失 \|让球\|≥2 场次** |
| `www.okooo.com/jingcai/kaijiang/` | 赛果 + 让球盘口 + 中奖 SP，可回溯数月 | **单次最多 5 天**；行内被注释的 `<td>指数</td>` 会造成列错位，**必须先剥离 HTML 注释** |
| `zx.500.com` / `odds.500.com/fenxi/*` | （欧赔 / 亚盘 / 基本面） | 被腾讯验证码拦截，**默认视为不可得**；降级到澳客或请用户提供页面文本 |

**默认不可得（除非另行打通）**：初盘 → 盘中 → 尾盘的赔率轨迹、成交量/热度、欧赔亚盘、基本面（伤病/轮换/交锋/赛程密度）。涉及这些维度的分析必须标注为推断或跳过，**不得伪造**。详细陷阱清单见 `references/data-sources.md`。

## 分析框架

对每场比赛按 **5 个维度**取证：**初盘 / 盘中 / 尾盘 / 基本面 / 赔率结构**。在当前数据边界下，可稳定获得的是 **终盘赔率结构 + 让球盘 + 赛果**；其余维度标注不可得。

赔率结构必算：
- **隐含概率**：对每个玩法做 `1/赔率` 归一化（`wbf_lib.implied`），得到市场概率分布与 overround。
- **胜平负**：最低赔率方向 = 市场热门；p_fav 分档（<50 / 50–60 / 60–70 / ≥70%）。
- **比分**：全部 31 档（26 固定档 + 胜/平/负其他），SP ≥ 15 归为高赔组。
- **进球数**：0–7+；算期望进球、P(≥4)、P(1–3)。
- **半全场**：9 组合；算反转组（胜平/负平/胜负/负胜）与半场平合计。

### 四条重点规则（必须执行）

| 规则 | 定义 | 本库已标定事实 |
|---|---|---|
| **爆冷（胜平负）** | 获胜方 SP ≥ 3.5 | 工作日 16.3% / 周末 19.5%；**方向以平局为主**（工作 27/49、周末 24/39）；盘口倾斜法 **0 命中** |
| **高赔比分** | 实际比分 SP ≥ 15 | 工作日 36.0% / 周末 34.5%；**与大球强相关**（大球 69.4% vs 小球 17.6%），但总进球赛前不可预测 → 仅事后筛选 |
| **大球** | 总进球 ≥ 4 | 工作日 37.3% / 周末 33.5%；深盘场次场均 3.9–4.1 球（显著高于浅盘 2.8–3.0） |
| **半全场反转** | 胜平 / 负平 / 胜负 / 负胜 | 工作日 11.0% / 周末 15.0%；**周末 83.3% 的"反转"终点其实是全场平**，真翻盘（胜负/负胜）仅 2.5% |

## 工作流

### A. 当日预测流

```bash
SK=<skill_dir>/scripts/wb_football.py
# 1) 抓当日四玩法页（date = 开球日期）
python "$SK" fetch-odds --start 2026-10-15 --end 2026-10-15 --out ./data
# 2) 解析 -> odds.json
python "$SK" parse-odds --dir ./data --out ./data
# 3) 结构分析 + 重点候选（按"销售日"筛场次；凌晨开球场次属于前一天期号）
python "$SK" analyze --data ./data --sale-date 2026-10-15 --out ./data
```
产出 `today_merged.json`（合并赔率矩阵）、`today_analysis.json`（归一化结构）、`today_analysis.txt`（A–E 五组候选：大球 / 胜平负结构 / 高赔比分 / 半全场 / 爆冷）。

### B. 历史回测流

```bash
# 1) 抓历史四玩法页（--days weekday|weekend|all；周末样本用 weekend）
python "$SK" fetch-odds --playid 354 271 270 272 --start 2026-09-15 --end 2026-10-13 --days all --out ./data
python "$SK" parse-odds --dir ./data --out ./data
# 2) 抓赛果（澳客，自动按 5 天分块）
python "$SK" fetch-results --start 2026-07-27 --end 2026-10-13 --out ./data
# 3) 合并（--days 按竞彩期号过滤，--before 截止日期，--limit 取最近 N 场）
python "$SK" build --results ./data/results.json --data ./data \
       --days weekday --before 2026-10-14 --limit 300 --out ./data
# 4) 回测
python "$SK" backtest --dataset ./data/master_odds.json --out-prefix ./data/bt300
```
产出 `master_odds.json`（主数据集，含 `o500` 终盘）、`bt300_report.txt`（命中率 / 重点子集 / 结构 / 分档 / ROI / 分让球子组）、`bt300.json`（逐场判定字段）。

> 已有旧格式赛果文件可用 `--extra a.json b.json` 一并并入（自动兼容三种 schema）。
> 500 赔率历史窗口只有 30 天：`--before` 超出窗口的场次会自动退化为"仅让球盘可跑"。

### C. 比对与校正流

```bash
# pred.json = [{"no":"周四012","home":"本菲卡","away":"凯尔特人",
#               "f1":"3","score":["2:0","3:1"],"goals":["2","3"],"htft":["3-3"]}, ...]
python "$SK" compare --pred ./pred.json --results ./data/results.json --out ./data/cmp
```
逐玩法命中率 + 逐场对照。随后按下面的"校正闭环"写结论。

### 校正闭环（每轮必做，不得只预测不校正）

1. 记录每场预测 vs 实际（逐玩法）。
2. 统计命中率：**总体 / 重点规则四条（爆冷·高赔·大球·反转）分开算**。
3. **错因分解**：未命中里有多少是平局？多少是方向押反？多少是赔率解读错？（本库长期教训：盘口法约 53–64% 的失误来自平局）
4. 结算 ROI（`roi_stats`），检查是否仍为负、CI 是否跨 0。
5. 输出「当前准确率最高的方法 + 适用条件 + 样本量 + 残余风险」，并写入 `references/calibration-log.md` 追加一条编号校正项。

## 输出格式（五段式）

```
#### 一、当日赛程与赔率概览
（表：比赛 | 让球 | 胜平负赔率 | 隐含概率 | 比分Top3 | 进球分布 | 半全场Top3）
#### 二、重点场次分析
- 爆冷候选（胜平负） - 高赔比分候选（SP≥15） - 大球候选（P(≥4)）
- 半全场反转候选（胜平/负平/胜负/负胜 + 半场平分支）
#### 三、预测结果
（表：比赛 | 胜平负 | 比分(首选+备选) | 进球数 | 半全场 | 置信度 | 依据的方法）
#### 四、赛果比对与校正
（表：预测 vs 实际 | 命中 | 错因 | 校正建议）
#### 五、当前最优预测方法
（方法描述 + 历史准确率 + ROI + 适用条件 + 样本量 + 不适用场景）
```

**置信度分级**（本库标定）：
- **高**：深盘（|让球| ≥ 2）跟盘方向；或市场热门 p ≥ 70%。
- **中**：A 级三条件（p ∈ [0.60,0.70) ∩ 最低赔 ∈ [1.30,1.60) ∩ 主胜热门）；主让（≤ −1）场次。
- **低**：浅盘（|让球| = 1）盘口法；隐含 Top1 类单点。
- **回避**：客让（≥ +1）场次；三路概率分散（最低赔 ≥ 2.0 且无明确热门）。
