# 校正日志（Calibration Log）

> **每完成一轮"预测 → 比对 → 校正"必须在此追加一条记录**，编号连续，写明：依据（哪个数字/哪次检验）、动作、状态（✅ 已落地 / ⚠ 待扩样观察 / ❌ 已证伪弃用）。
> 目的：让"当前最优方法"可追溯，防止未经检验的直觉被当成结论。

## 编号约定

- **C\***：来自**工作日**样本（排除周六/周日）的校正。
- **W\***：来自**周末**样本的校正（与 C 严格区分，因环境显著不同）。
- 今后新增：按样本环境继续用 C / W 前缀，同轮内连续编号。
