# 足彩预测大师（football-lottery-analyst）

竞彩足球（足彩）全流程、多维度、可校正的预测分析与历史回测专家。基于公开赔率与开奖数据做**统计分析与回测**，输出可复验的胜平负、比分、进球数与半全场预测，并持续校正方法。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **四玩法赔率采集与解析**：`trade.500.com/jczq/`（playid 354/271/270/272）的胜平负、比分、进球数、半全场终盘赔率；`www.okooo.com/jingcai/kaijiang/` 的赛果、让球盘口与中奖 SP。内置 HTML 陷阱清洗（注释列错位、嵌套 table 截断、属性顺序不一致、gb18030 编码）。
- **隐含概率建模**：每个玩法做 `1/赔率` 归一化，给出市场概率分布与 overround（实测 1.129，抽水 ≈ 12.9%）；输出胜平负热门方向与 p_fav 分档、31 档比分分布、进球数期望与 P(≥4)、半全场 9 组合及反转组。
- **五维取证框架**：初盘 / 盘中 / 尾盘 / 基本面 / 赔率结构；当前数据边界下可稳定获得终盘赔率结构 + 让球盘 + 赛果，其余维度显式标注不可得。
- **历史回测**：批量回测 N 场（支持工作日 / 周末 / 全部过滤、截止日、取最近 N 场），输出总体命中率、四条重点规则分开统计、结构分档、分让球子组与 ROI / t / 95% CI。
- **校正闭环**：逐场预测 vs 实际比对、错因分解（平局 / 方向押反 / 赔率解读错）、ROI 检验，输出「当前准确率最高的方法 + 适用条件 + 样本量 + 残余风险」。

## 内置四条重点规则

| 规则 | 定义 | 已标定事实 |
|---|---|---|
| 爆冷 | 获胜方 SP ≥ 3.5 | 工作日 16.3% / 周末 19.5%，方向以平局为主 |
| 高赔比分 | 实际比分 SP ≥ 15 | 工作日 36.0% / 周末 34.5%，与大球强相关 |
| 大球 | 总进球 ≥ 4 | 工作日 37.3% / 周末 33.5% |
| 半全场反转 | 胜平 / 负平 / 胜负 / 负胜 | 工作日 11.0% / 周末 15.0% |

## 使用示例

- 分析今天的竞彩足球赛程，给出胜平负、比分、进球数和半全场预测。
- 回测最近 300 场工作日赛事，统计逐玩法命中率并校正预测方法。
- 对比工作日与周末的平局率差异，找出准确率最高且经得起 ROI 检验的方法。

## 安装

```
C:\Users\Admin\.workbuddy\plugins\marketplaces\my-experts\plugins\football-lottery-analyst\
```

```bash

```
