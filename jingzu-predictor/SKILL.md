# 竞足预测大师 · 分环境双轨预测与回测（jingzu-predictor）

> **核心命题**：不是「给一个结果」，而是 —— **分析 → 预测 → 比对赛果 → 校正 → 收敛出「工作日」与「周末」两套各自最优、且互不相同的方法集**，并用 **ROI + 显著性**检验它是否只是运气。

## 五条铁律（先读，违反即作废）

1. **不编造数据**。赔率页打不开、字段缺失、付费墙 → 必须显式标注「数据缺失 / 不可得」，**绝不用记忆或推测填补赔率、赛果、伤停**。
2. **分环境铁律（本 skill 的立身之本）**。**周末 ≠ 工作日**：平局率 28.0% vs 19.7%（**z=2.16, p=0.031 ★**），让球盘结果≠不让球结果 56.5% vs 50.7%。**两套方法集零重叠，任何规则不得跨环境套用**（最典型的反例：平赔≤3.4 押平局，工作日 ROI **−34.42%** vs 周末 **+31.31%**，符号相反）。产出必须声明样本属于哪个环境。
3. **多选计注口径**：多选型打法（比分/进球数/半全场 Top3 等）结算时 **注数 = 选数**。按「每场 1 注」会把 比分Top3 由 −28.73% 误算成 **+113.81%**、半全场Top3 由 −7.64% 误算成 **+177.08%** —— 系统性制造假正期望。
4. **命中率 ≠ 盈利**。竞彩 overround ≈ 1.13（抽水 ≈ 13%）。任何「某方法更好」的结论必须先过 ROI 门槛（ROI / t / 95%CI），**CI 跨 0 即等于零**。本库至今**没有任何方法被证明为正期望**。
5. **诚实披露 scope**。每份产出末尾列明：本轮不可得的维度、可得性折损（500 终盘实际覆盖工作日仅 50%、周末 70%）、样本量不足项（n<30 一律标「继续扩样」），并明确区分**已结论 vs 观察项 vs 已证伪**。

## 何时使用

- 分析某日竞彩赛程，要四玩法预测 → 先判环境（工作日/周末），再套对应方法集。
- 「回测 N 场 / 校正方法 / 找准确率最高的方法」→ 走双环境回测流。
- 出现：爆冷、平局、高赔比分、大球、半全场反转、深盘跟盘、A 级三条件、盘口倾斜、概率差。
- 给出 titan007 / 球探 / 竞彩官方 SP 页面，要求解读。

## 四专项规则（摘要）

> 完整候选排名与 ROI 见 **`references/special-dimensions.md`**。

| 专项 | 工作日 | 周末 |
|---|---|---|
| 平局识别 | 平赔≤3.40 且 进球最热≤2 → **28.2%**（基准 19.3%） | **平赔≤3.40 → 41.7%**（基准 24.1%，**1.73x**） |
| 爆冷预警 | **平赔≤3.40 → 58.0%**（验证 60.5%） | **概率差≤10pp → 75.9%**（验证 78.6%） |
| 平局下注 | 平赔≤3.5 押{客,平} 66.1%、ROI +0.93%（≈打平） | **平赔≤3.4 押平 → ROI +31.31%**（t=1.38，未显著） |
| 高赔比分识别 | 进球最热≥3 → 40.9%（**仅 1.08x**） | 进球最热≥3 → 38.6%（**仅 1.24x**） |
| 大球识别 | 概率差≥20pp 且 最热≥3 → **42.7%**（基准 35.3%） | 进球最热≥3 → 36.4%（基准 28.4%） |
| 半全场反转识别 | 平赔≤3.40 → 16.0%（基准 10.7%） | 32.3% → **验证崩至 11.8%（已证伪）** |

**三条硬结论**：① 深盘（\|让球\|≥2）**零爆冷**（工作日 0/8、周末 0/1），未命中**全是平局** → 深盘必挂防冷平；② **高赔比分不可事前识别**（20 次评估最大提升仅 1.24x，且基准率本身 31–38%，"高赔"≠冷门）；③ **专押大球为负期望**（工作日 −27.74%、周末 −38.05%），赔率已被市场充分定价。

## 工作流

### A. 当日预测流

```bash
PY=python3
SK=<skill_dir>/scripts

# 1) 判环境：按竞彩期号前缀（周X）——周一~周五=工作日方法集，周六/周日=周末方法集
# 2) 采集（titan007，见 references/data-sources.md 的 URL 与提取提示词）
# 3) 把四玩法 SP 填进数据字典后，用与回测**同一份**规则代码判定：
$PY $SK/today_predict.py --input $SK/examples/today_2026-10-16.json   # 换成当日数据文件
```

产出：`out/today_<date>.txt` —— 今日结构（深盘有无、主让/客让分布）+ 逐场指标（p / 概率差 / 让球盘最热）+ **各档位出手判定**。

> **关键**：`today_predict.py` 直接 `from env_rules import wd_rules, we_rules, predict`，与回测共用同一份规则，**不得手算**。

### B. 双环境回测与校正流

```bash
# 1) 全变体排名（56 变体 × 5 玩法 × 2 环境）
$PY $SK/sep_backtest.py
# 2) 固化方法集 + 错因分解 + 显著性 + 逐场 CSV
$PY $SK/sep_final.py
# 3) 四专项（识别层 precision/recall/lift + 预测层 ROI）
$PY $SK/sep_special.py
# 4) 回归校验（防止已修复的口径 bug 复现）
$PY $SK/check_contam.py
```

数据集路径默认取环境变量 `JZ_DATA_DIR`，未设置时回退到脚本同级 `../hist/`。需要两个文件：
`master300_odds.json`（工作日）、`master200_wk_odds.json`（周末）。

### 校正闭环（每轮必做）

1. 逐场记录「预测 vs 实际」（逐玩法）。
2. 命中率：**总体 + 四专项分开算**。
3. **错因分解**：未命中里多少是平局、多少是方向押反。（长期教训：盘口法失误 53–64% 来自平局）
4. 结算 ROI（注数 = 选数），看 CI 是否跨 0。
5. 输出「当前最优方法 + 适用条件 + 样本量 + 残余风险」，追加一条编号校正项到 `references/calibration-log.md`。

## 输出格式（五段式）

```
#### 一、当日赛程与赔率概览   （比赛 | 让球 | 欧指/SP | 隐含概率 | 亚指 | 大小球）
#### 二、重点场次分析         （爆冷/平局候选 · 高赔比分候选 · 大球候选 · 半全场反转候选）
#### 三、预测结果             （比赛 | 胜平负 | 比分 | 进球数 | 半全场 | 置信度 | 方法标签）
#### 四、赛果比对与校正       （预测 vs 实际 | 命中 | 错因 | 校正建议）
#### 五、当前最优预测方法     （方法 + 适用条件 + 命中率 + ROI + 样本量 + 不适用场景）
```

模板文件见 `assets/report-template.md`。

**置信度分级**：高 = 深盘跟盘 / 市场热门 p≥70% / 半全场深盘 Top3；中 = A 级三条件（仅周末）/ 主让场次；低 = 浅盘盘口法 / 隐含 Top1 单点；**回避** = 客让场次、周末让球胜平负、三路分散（最低赔≥2.0 且无明确热门）。
