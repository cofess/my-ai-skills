# jingzu-predictor · 竞足预测大师

> 中国竞彩足球**「分环境双轨」**预测与回测技能包 —— **工作日与周末各用一套互不相同、经留出验证的固化方法集**。
> 目标不是「给一个结果」，而是：**分析 → 预测 → 比对赛果 → 校正 → 收敛出两套各自最优且零重叠的方法集**，并用 **ROI + 显著性**检验它是否只是运气。

**定位**：基于公开数据（titan007 球探网赔率 + 竞彩官方 SP + 赛果）的**统计分析与历史回测**，属信息分析用途，**不构成投注建议**。

## 这个包能做什么

| 能力 | 说明 |
|---|---|
| **分环境路由** | 按竞彩期号判定环境（周一~周五=工作日 / 周六周日=周末），套用**对应**那一套方法集，两套规则**零重叠、绝不混用** |
| **四玩法预测** | 胜平负 / 比分（31 档）/ 进球数（0–7+）/ 半全场（9 组合），输出隐含概率、概率差、Top3 与置信度分级 |
| **titan007 数据链采集** | 竞彩赛程页五玩法 SP（含不让球胜平负）、亚指、大小球、数据分析页（含伤停简报），内置数字串解码契约与陷阱清单 |
| **双环境回测** | 工作日 300 场 + 周末 200 场，输出命中率、留出验证、错因分解、ROI / t / 95% CI |
| **四专项规则库** | 爆冷预警、平局识别与下注、高赔比分识别、大球识别、半全场反转识别 |
| **规则真源共用** | `scripts/env_rules.py` 为**唯一规则源**，回测与当日预测 `import` 同一份代码 —— 杜绝「回测一套、预测另一套」的口径漂移 |

## 核心结论：两套零重叠方法集

**6/6 档位规则零重叠** —— 两环境不含任何同一条规则。

**工作日（n=300，2026-08-29~10-13）**

| 档位 | 规则 | n | 命中率 | 留出验证 | ROI |
|---|---|---|---|---|---|
| 胜平负·主推 | 深盘跟盘 \|让球\|≥2 | 44 | **88.6%** | 92.9% | +5.00%（注 14） |
| 胜平负·可结算 | 主胜热门且 p≥60% | 67 | 77.6% | 83.9% | +0.00%（t=0.00） |
| 让球胜平负 | 让球玩法热门 p≥60% | 35 | 54.3% | 71.4% | −25.17%（t=−2.13） |
| 比分 | Top3 ∩ 概率差<20pp | 97 | 33.0% | 34.2% | −18.33% |
| 进球数 | 固定 1–3 球 ∩ 仅主让 | 201 | 57.7% | 60.7% | −11.14% |
| 半全场 | Top3 ∩ 仅深盘场 | 40 | **90.0%** | 92.3% | −14.20% |

**周末（n=200，2026-09-12~10-12）**

| 档位 | 规则 | n | 命中率 | 留出验证 | ROI |
|---|---|---|---|---|---|
| 胜平负·主推 | A 级三条件 | 20 | 75.0% | 90.9% | +3.35%（t=0.24） |
| 胜平负·可结算 | 市场热门 p≥70% | 18 | 83.3% | 83.3% | −2.50% |
| 主让场补充 | 盘口倾斜法（仅主让） | 129 | 60.5% | 73.6% | +0.02%（t=0.00） |
| 让球胜平负 | **【回避】** | — | — | — | — |
| 比分 | Top3 ∩ 仅客让场 | 71 | 33.8% | 48.1% | −15.28% |
| 进球数 | 隐含 Top3（全样本） | 200 | **64.5%** | 63.8% | −13.42% |
| 半全场 | Top3 ∩ 热门 p≥60% | 57 | 78.9% | 77.8% | −13.98% |

### 为什么必须分开（量化依据）

| 指标 | 工作日 | 周末 | 判定 |
|---|---|---|---|
| 平局率 | 19.7% | **28.0%** | **z=2.16, p=0.031 ★** |
| 让球盘结果 ≠ 不让球结果 | 50.7% | **56.5%** | 周末让球不可测 → 回避 |
| 进球 Top3 命中 | 58.2% | **64.5%** | 周末值域更集中 |

**平局率是分水岭**：工作日平局少 → 盘口方向法成立；周末平局多 → 盘口法塌陷，必须换成赔率条件筛选法。
最典型反例：**平赔≤3.4 押平局，工作日 ROI −22.41% vs 周末 +36.27%（符号相反）**。

## 四专项规则

| 专项 | 工作日 | 周末 |
|---|---|---|
| 平局识别 | 平赔≤3.40 且 进球最热≤2 → **31.0%**（基准 20.4%） | **平赔≤3.40 → 43.5%**（基准 28.5%，**1.53x**） |
| 爆冷预警 | **平赔≤3.40 → 55.9%**（验证 60.5%） | **概率差≤10pp → 80.6%**（验证 78.6%） |
| 平局下注 | 平赔≤3.5 押{客,平} 64.5%、ROI −4.62% | **概率差≤15pp 押{主,平} → ROI +16.93%**（t=2.19，**已达显著**） |
| 高赔比分识别 | 进球最热≥3 → 40.6%（**仅 1.12x**） | 进球最热≥3 → 41.3%（**仅 1.18x**） |
| 大球识别 | 概率差≥20pp 且 最热≥3 → **42.5%**（基准 35.6%） | 进球最热≥3 → 38.0%（基准 30.6%） |
| 半全场反转识别 | 平赔≤3.40 → 16.1%（基准 11.5%） | 25.6% → **验证崩至 11.8%（已证伪）** |

**三条硬结论**
1. **深盘低爆冷**：\|让球\|≥2 的深盘，爆冷 1/14（工作日）、1/6（周末），远低于基准；未命中**以平局为主** ⇒ 深盘必挂防冷平。
2. **高赔比分不可事前识别**：10 候选 × 2 环境共 20 次评估，最大提升仅 **1.18x**；且基准率本身高达 31–38%，「高赔」≠ 冷门。
3. **专押大球为负期望**：{4,5,6,7+} 工作日 **−23.83%** / 周末 **−32.56%**，赔率已被市场充分定价。

## 快速开始

依赖：**Python 3.8+（仅标准库）**，无需 pip 安装。

```bash
PY=python3
SK=scripts

# ── A. 当日预测流 ──────────────────────────────
# 1) 判环境（周一~周五=工作日方法集；周六/周日=周末方法集）
# 2) 采集 titan007 四玩法 SP（URL 与提取提示词见 references/data-sources.md）
# 3) 填进数据字典后用与回测同一份规则判定：
$PY $SK/today_predict.py --input $SK/examples/today_2026-10-16.json
#  →  out/today_<date>.txt

# ── B. 双环境回测与校正流 ──────────────────────
export JZ_DATA_DIR=/path/to/hist     # 需 master300_odds.json + master200_wk_odds.json
$PY $SK/sep_backtest.py              # 1) 全变体排名
$PY $SK/sep_final.py                 # 2) 固化方法集 + 显著性 + 逐场 CSV
$PY $SK/sep_special.py               # 3) 四专项
$PY $SK/check_contam.py              # 4) 回归校验
```

> **关键**：`today_predict.py` 直接 `from env_rules import wd_rules, we_rules, predict`，与回测**共用同一份规则，不得手算**。

各脚本用法与验证基线详见 [`scripts/README.md`](scripts/README.md)。

## 数据源

| 源 | URL 模板 | 能给 | 陷阱 |
|---|---|---|---|
| 竞彩赛程页 | `cp.titan007.com/buy/jingcai.aspx?typeID=101~104&date=YYYY-MM-DD` | 让球盘口 + **不让球/让球**胜平负/进球数/半全场/比分 SP（**五玩法全可得**，可回溯历史） | 须带 cache-buster（否则 CDN 陈旧缓存静默返回错页 **T12**）；比分 31 档服务端已渲染、可直接解析（非「折叠不可得」） |
| 亚指 | `vip.titan007.com/AsianOdds_n.aspx?id={id}` | 盘口 + 上下盘水位 + 变化史 | 页面极大，必须限行提取 |
| 大小球 | `vip.titan007.com/OverDown_n.aspx?id={id}&l=0` | 盘口 + 大小水位 + 升降次数 | 同上；升/降盘次数是关键信号 |
| 数据分析 | `zq.titan007.com/analysis/{id}cn.htm` | 排名/近况/盘路/H2H/伤停/阵容评分 | 最高效聚合源，优先抓 |
| 情报页 | `users.titan007.com/member/qingbao.aspx` | 伤停情报 | **付费墙** → 标记缺失，用分析页「赛前简报」兜底 |

⚠️ **默认不可得**：初盘→盘中→尾盘漂移（赛程页仅初盘/即时两值）、成交量热度。
**不让球 SPF 可得**（`cell_52/53/54`，勘误 **D17**；仅深盘场两源均不售）；**完整比分 SP 可得**（31 档服务端渲染；勘误 **D13**）；比分 SP 变化页返回无缝拼接串，**拒绝自造**。产出时必须显式标注该 scope 边界。

## 五条铁律

1. **不编造数据** —— 打不开 / 字段缺失 / 付费墙一律显式标注，绝不用记忆或推测填补赔率、赛果、伤停。
2. **分环境铁律** —— 两套方法集零重叠，任何规则不得跨环境套用；产出必须声明样本属于哪个环境。
3. **多选计注口径** —— 多选型打法结算时 **注数 = 选数**（按「每场 1 注」会系统性制造假正期望）。
4. **命中率 ≠ 盈利** —— 竞彩 overround ≈ 1.13，任何「某方法更好」必须先过 ROI 门槛（ROI / t / 95%CI），CI 跨 0 即等于零。
5. **诚实披露 scope** —— 列明不可得维度、可得性折损、样本量不足项（n<30 标「继续扩样」），区分**已结论 vs 观察项 vs 已证伪**。
